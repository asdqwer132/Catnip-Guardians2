# 분할 전투와 아이템 합성 통

GameScene은 왼쪽의 기존 식물 방어 전투와 오른쪽의 물리 합성 통으로 나뉩니다. UpgradeScene은 **스킬트리 / 보조식물 / 상자 구매 / 사전**을 제공합니다. 일반 제작·가방 편성 탭과 기존 가방 사용 입력은 비활성화했습니다. 원래 아이템·효과·프리팹·이전 스크립트와 GUID는 보존합니다.

## 플레이 방법

1. 업그레이드 씬의 상점에서 시리즈별 **재료 상자**를 구매합니다.
2. 스킬트리에서 원하는 통을 강화하고 **전투 시작**을 누릅니다.
3. 게임 씬 **왼쪽 클릭**으로 투척 목표를 지정합니다. 이동은 기존처럼 왼쪽 전투 화면에서 오른쪽 클릭입니다.
4. 오른쪽 통에 주기적으로 재료가 떨어집니다. **같은 ItemData 두 개**가 닿으면 연결된 다음 아이템 하나로 합성됩니다.
5. 통 안의 아이템을 **클릭**하면 하나를 던집니다. **드래그**하면 원형 선택 범위가 지나간 아이템들을 모으고, 통 안에서 놓을 때 함께 던집니다. 통 밖에서 놓거나 **선택 취소**를 누르면 취소합니다.
6. **1~8** 또는 상단 버튼으로 시리즈별 통을 전환합니다. 이미 들어간 아이템은 유지됩니다.

선택한 아이템은 색이 바뀌며, 선택 도중 합성되지 않습니다. 투척에 성공한 아이템만 제거합니다. 목표 미지정·일시정지·쿨다운 중에는 투척하지 않습니다. 클릭/드래그 쿨다운은 통마다 별개입니다. 합성 통의 물리는 별도의 PhysicsScene2D에서 실행하므로 전투의 충돌과 중력 설정에 영향을 주지 않습니다. 모든 통이 같은 TokenView 풀을 공유하며, 물리 콜백 도중 반환한 객체는 같은 물리 스텝에서 재사용하지 않습니다.

적 출현·식물 체력·처치 성장치·단계 보상·결과 확정 흐름은 유지합니다. 투척과 착지 이후 효과는 기존 ItemThrowExecutor/ItemEffectExecutor로 실행하므로 버프·상태 반응·장판 반응·소환·종료 후 효과를 재사용합니다. 새 투척의 Source Bag은 비어 있습니다.

## 공통 설정

`Assets/Data/MergeGame/MergeGameCatalog.asset`을 두 씬에서 공유합니다.

| 옵션 | 기본값과 의미 |
| --- | --- |
| Supply Mode | Consume Stock: 실제 주입할 때 보유 재료 1개 소비 |
| Repeat Owned Material | 공급 옵션을 이 값으로 바꾸면, 1개 이상 보유한 재료를 소비하지 않고 반복 생성 |
| Selection Delivery | On Release: 클릭/드래그 종료 시 투척. Confirm Selection은 선택을 모은 뒤 **선택 아이템 던지기** 버튼으로 투척 |
| Inject Into Inactive Containers | 꺼짐. 켜면 다른 통도 자동 주입하며 Consume Stock에서는 해당 보유량도 소비 |
| Scatter Radius | 0.35: 목표 주변 원 안으로 착지점을 분산. 0은 동일 위치 |
| Throw From Owner | 꺼짐: 통 아이템의 화면 위치를 전투 카메라 좌표로 변환해 오른쪽에서 진입. 켜면 플레이어 위치에서 출발 |
| Throw Start Offset | 출발점에 더할 월드 오프셋 |

공급/선택 방식은 아직 별도 답변이 없어 위 값을 초기 기본값으로 두었습니다. 두 방식 모두 옵션으로 구현했습니다. 기본 상태에서는 선택한 통만 추가 주입하며, 다른 통의 기존 아이템도 계속 떨어지고 합성됩니다.

가득 찬 통이나 막힌 주입구는 해당 주입을 건너뛰고 재료를 차감하지 않습니다. 넘침에 의한 별도 패배 조건은 추가하지 않았습니다. 기본 통은 크기 6×8, 주입 간격 1.5초, 주입구 1개, 최대 96개, 드래그 반경 0.6, 클릭 대기 0.3초, 드래그 대기 1초입니다.

## 합성 경로와 투척 모션

`Assets/Data/MergeGame/Containers`에 무기·음식·광물·몬스터·낚시·식물·기계·마법 통이 있습니다.

- **Injection Materials**: 자동 투입할 재료 목록입니다. 이름이나 Category로 재료 여부를 추정하지 않습니다.
- **Items → Item / Merge Result / Radius**: 아이템, 같은 아이템 두 개의 합성 결과, 실제 물리 반경입니다. 결과도 Items에 등록합니다. Merge Result가 비어 있으면 최종 단계입니다.
- **Base Stats**: 통 크기·주입 간격·주입구·선택 반경·쿨다운입니다.
- **Throw Options**: 통마다 기존 투척 프리팹·이미지·비행 시간·아크·스핀/방향 회전을 설정합니다.

초기 연결은 **Material N 두 개 → 같은 시리즈의 N번 아이템**, 이후 **N번 두 개 → N+1번**, 30번은 최종 단계입니다. 낚시 재료는 15종, 나머지는 시리즈별 9종입니다. 이 순서는 바로 플레이하기 위한 초기 경로이며, 숫자가 전투 성능 순위를 뜻하지 않습니다. 원하는 경로로 Merge Result를 바꾸면 됩니다. 기존 ItemData의 효과와 수치는 수정하지 않았습니다.

## 통 스킬트리

시리즈마다 6개 가지·가지별 2단계로 **총 96개 노드**가 있습니다. 기존 SkillTreeManager의 재화/선행 스킬 판정을 사용하고, 2단계는 같은 가지의 1단계를 요구합니다. 현재 비용은 Gold 50 / 100이며 노드에서 수정할 수 있습니다.

| 가지 | 단계별 효과 |
| --- | --- |
| 통 크기 | 너비·높이 각각 ×1.2 |
| 주입 속도 | 초당 주입 속도 ×1.25: 간격을 1.25로 나눔 |
| 주입구 | +1개 |
| 드래그 범위 | 선택 반경 +0.25 |
| 클릭 대기 감소 | 클릭 쿨다운 ×0.8 |
| 드래그 대기 감소 | 드래그 쿨다운 ×0.8 |

`MergeContainerUpgradeReward`의 **Container**는 대상 통이며 비우면 모든 통에 적용합니다. **Skill ID**는 노드의 Data ID와 같아야 합니다. 공유 에셋은 기본값만 보관하고 강화 결과는 런타임 복제본에 계산합니다. 씬을 다시 열어도 구매 기록을 확인하여 재구매/중복 적용을 막습니다.

스킬 화면 하단의 **기존 특수 스킬 보기**로 기존 트리를 볼 수 있습니다. 제거된 가방/가방 슬롯 보상은 통 모드에서 구매할 수 없습니다. 스킬트리 탭을 다시 누르면 통 강화 화면으로 돌아옵니다.

## 사전·보조식물·저장 범위

사전에는 ItemData 330개와 EnemyStatData 31개를 연결했습니다. 아이템 이름·설명·시리즈·등급·보유량·다음 합성 결과, 적의 체력·피해·속도·사거리·공격 간격·성장치를 표시합니다. 검색과 30개 단위 페이지 이동을 지원합니다. 항목 추가는 Catalog의 사전 목록에서 합니다. 검색 중에는 게임 단축키가 발동하지 않습니다.

보조식물의 기존 레시피/재료 화면을 유지하고, 제거된 일반 제작 매니저를 요구하던 선택 조건을 수정했습니다. 준비한 보조식물 재료/결과와 보유 재료는 씬을 오갈 때 보존합니다. 기존에 꺼져 있던 전투 시작 자동 배치는 이번에 활성화하지 않았습니다.

`MergeGameSession`이 씬 사이의 보유량과 통 스킬을 유지합니다. 앱 종료 뒤의 디스크 저장 기능을 뜻하지 않습니다. Consume Stock에서 통에 이미 투입한 재료는 소비한 것이며, 전투 재시작/종료 시 통 안 아이템은 초기화합니다.
